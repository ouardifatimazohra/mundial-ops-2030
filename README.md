# 🏆 MUNDIAL-OPS 2030

> Plateforme DevOps intelligente d'orchestration de la Coupe du Monde 2030

## 🎯 Vision

MUNDIAL-OPS 2030 est une infrastructure DevOps auto-pilotée par IA qui orchestre les services numériques critiques de la Coupe du Monde 2030, hébergée sur les 3 pays co-organisateurs : **Maroc 🇲🇦, Espagne 🇪🇸, Portugal 🇵🇹**.

## 🏗️ Architecture

- **3 Microservices** : Billetterie (Casablanca), Streaming (Madrid), Stade (Lisbonne)
- **Cerveau IA** : Détection d'anomalies (Isolation Forest) + Agent Claude pour explications intelligentes
- **Observabilité** : Prometheus + Grafana
- **CI/CD** : GitHub Actions
- **Dashboard** : React Mission Control
